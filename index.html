Prerequisites
1
On your Android: Settings → About phone → tap Build number 7× to enable Developer Options
2
Go to Developer Options → enable USB Debugging (and Wireless Debugging if using Wi-Fi)
3
Install scrcpy on your computer (see commands below)
Install scrcpy
Windows
$winget install Genymobile.scrcpy
macOS
$brew install scrcpy
Linux (Ubuntu/Debian)
$sudo apt install scrcpy
Mirror your Android
USB (plug phone into computer)
$scrcpy
Wi-Fi (same network, Android 11+)
$scrcpy --tcpip
Wi-Fi (older Android — pair manually)
$adb connect 192.168.1.XX:5555
$scrcpy
With recording
$scrcpy --record screen.mp4
Higher quality + no border
$scrcpy --max-size=1920 --no-window-border
scrcpy is open-source, zero-lag, and supports audio mirroring (Android 12+). No app installed on your phone — it works entirely via ADB. Source: github.com/Genymobile/scrcpy
